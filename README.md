# M&G Segurança Eletrônica — site

Site institucional estático (HTML + CSS + JS puro), publicado via GitHub Pages.

- `index.html` — página única com todo o conteúdo e estilos
- `assets/` — logo, ícones, imagem Open Graph e fotos dos produtos
- `site.webmanifest` — manifesto para ícones em dispositivos móveis

Para editar textos, produtos ou links de WhatsApp, edite o `index.html` diretamente.
